# فصل ۳ — Triggerها

هر workflow با یه **Trigger** شروع می‌شه؛ یعنی اتفاقی که باعث اجرا شدن workflow می‌شه.

## انواع Trigger

### 1. Manual Trigger
برای تست دستی — با کلیک روی دکمه‌ی Execute اجرا می‌شه.

### 2. Schedule Trigger
اجرا در بازه‌های زمانی مشخص (مثل هر روز ساعت ۸ صبح):

```
Mode: Every Day
Hour: 8
Minute: 0
```

### 3. Webhook Trigger
وقتی یه درخواست HTTP از بیرون (مثلاً از یه فرم یا سرویس دیگه) به یه URL مشخص ارسال می‌شه، workflow اجرا می‌شه. جزئیات کامل توی [فصل ۵](../05-webhooks) هست.

### 4. App Triggers
خیلی از سرویس‌ها (تلگرام، گوگل‌فرم، ایمیل) Trigger اختصاصی خودشون رو دارن. مثلاً **Telegram Trigger** با هر پیام جدید در ربات فعال می‌شه.

## مقایسه سریع

| Trigger | زمان اجرا | کاربرد رایج |
|---------|-----------|-------------|
| Manual | با کلیک کاربر | تست و توسعه |
| Schedule | زمان‌بندی‌شده | گزارش‌گیری روزانه، بکاپ |
| Webhook | با درخواست HTTP بیرونی | اتصال فرم، پرداخت، سرویس‌های شخص‌ثالث |
| App Trigger | رویداد داخل اپ (پیام، ایمیل و...) | ربات تلگرام، اتوماسیون ایمیل |

## تمرین این فصل

یه Schedule Trigger بساز که هر ۵ دقیقه یک‌بار اجرا بشه و بعدش یه Node به اسم `NoOp` بهش وصل کن تا اجرا شدنش رو توی Execution Log ببینی.
